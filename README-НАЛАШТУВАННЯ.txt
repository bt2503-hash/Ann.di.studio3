# ann.di.studio — підключення спільної бази даних

## Що виправлено
- Замовлення більше не зберігаються тільки в localStorage браузера.
- Оформлення замовлення записується в Supabase із прив'язкою до `user_id`.
- Додано реєстрацію, вхід, вихід і особистий кабінет покупця.
- Покупець бачить тільки власні замовлення.
- Адмінпанель входить через Supabase Auth і завантажує спільний список замовлень.
- Зміна статусу та видалення замовлення в адмінці записуються в базу.

## 1. Створити базу
1. Відкрий https://supabase.com/ і створи безкоштовний проєкт.
2. Відкрий SQL Editor → New query.
3. Скопіюй весь вміст `supabase-setup.sql` і натисни Run.
4. У Authentication → Providers → Email увімкни Email provider. Для тестування можна тимчасово вимкнути Confirm email; для реального запуску краще залишити підтвердження пошти.

## 2. Підключити сайт
1. У Supabase відкрий Project Settings → API.
2. Скопіюй Project URL та anon/public key.
3. Відкрий `supabase-config.js` і встав їх замість:
   - `PASTE_SUPABASE_PROJECT_URL_HERE`
   - `PASTE_SUPABASE_ANON_KEY_HERE`
4. Збережи файл і завантаж усю папку сайту на Netlify повторно.

Використовуй тільки anon/public key у фронтенді. НІКОЛИ не вставляй `service_role` key у сайт.

## 3. Створити акаунт адміністратора
1. Відкрий опублікований сайт, натисни іконку користувача та зареєструй окремий акаунт адміністратора.
2. Підтверди email, якщо це ввімкнено.
3. У Supabase → Authentication → Users відкрий цього користувача.
4. У полі User Metadata НЕ встановлюй роль. У полі App Metadata додай:
   `{ "role": "admin" }`
   Збережи зміни.
5. Відкрий `/admin.html`, увійди email і паролем цього акаунта.

## 4. Як це працює
- Кожен покупець реєструється/входить і оформлює замовлення під своїм акаунтом.
- Замовлення зберігається у спільній базі, тому видно з іншого пристрою після входу в той самий акаунт.
- Адмін бачить усі замовлення та може змінювати статус.

## Важливо
- Якщо Supabase не налаштований, замовлення не оформиться: це навмисно, щоб замовлення не губилися в браузері.
- Каталог товарів та налаштування вмісту адмінпанелі в цій версії ще зберігаються локально в браузері. Спільна база зараз підключена для акаунтів і замовлень.
- Це базова інтеграція. Перед комерційним запуском перевір email-підтвердження, політику приватності, резервні копії та реальні сценарії замовлення.
